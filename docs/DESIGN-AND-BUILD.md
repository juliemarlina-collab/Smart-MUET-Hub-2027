# Design direction and build sequence

The supplied references are combined by layout purpose, not applied as one identical card grid everywhere.

| View | Design reference | Interpretation |
|---|---|---|
| Welcome | SkillUp poster and bold portfolio | Oversized editorial title, dark animated header, purple hero folder, supplied skill illustration, small lime/yellow accents |
| Know MUET | School brochure and circular-economy presentation | Two-column introduction, chapter margin, score band, four expandable paper notes |
| Four Skills | Interactive cards and poster blocks | Skill tabs, colourful illustration panel, tactile technique letters and revealed examples |
| Learning Route | Numbered implementation layout | Six expandable steps and a contrasting personal-goal panel |

Palette: ink #17151E, purple #5625DC, cobalt #3542E8, yellow #FFDA16, teal #00CDB4, magenta #C90C9F, orange #FF792F and lime #C9F653. Fonts are bundled locally with their OFL licences.

The supplied illustration files are copied as assets. Reference posters are used to guide composition and colour; their unrelated claims, statistics and brand names are not copied into MUET content.

Animation has specific roles: the header contracts after scrolling; its small phrase changes gently; the active folder opens with a brief perspective transition; hero elements float; details reveal on interaction. The shared pause preference and OS setting stop these movements.

Build order: finish/review Part 1, then Part 2 accounts; Part 3 component guides; Part 4 Book; Part 5 practice; Part 6 progress. When an authentication provider is chosen in Part 2, implement actual verification rather than displaying a fabricated OTP flow.

Each later part should use the shared tokens and header, retain the agreed palette, vary the layout to suit its learning function and be checked on mobile before being connected.
