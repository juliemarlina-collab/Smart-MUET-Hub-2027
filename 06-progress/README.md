# Me · My learning

Open `index.html`. This page reads existing browser records from the PDF reader, Reading/Listening/Writing guides and Speaking PREP Lab. It shows learner-marked progress, saved Speaking reflections and a JSON export. Speaking guide step counts are not tracked, so none are invented. Audio is excluded from the export and is managed in the lab.

Band estimates, XP, badges, shared review scheduling and cross-device sync remain planned. No data is uploaded by this dashboard. The account link opens the existing account module, whose service is disabled by default until configured.


Part 6 update: Me now shows cards for all four labs, a merged reflection timeline (all labs, newest first) and a Review again count from `smh.review.queue.v1`. The JSON export includes every lab record and the review queue.
